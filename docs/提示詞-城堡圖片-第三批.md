# 虛擬公會城堡：第三批圖片提示詞（新房間的家具）

> 城堡骨架的房間都已經可以逛，家具先用色塊表示。這份是各房間需要的圖。
> 共同規格、風格說明與上傳方式和 `docs/素材規格-城堡圖片.md` 相同：**在同一個 ChatGPT 對話裡先貼「共同風格說明」**，再一張一張貼下面的提示詞。
> 每張都是：溫暖的奇幻像素風、俯視 3/4 視角、透明背景、不要發光特效、不要文字。

## 怎麼交給 AI 代理

1. 照下表檔名命名，上傳到 GitHub 的 `docs/素材/城堡原圖/`；或
2. 直接貼在對話裡，並依序說明是哪幾張（例如「依序是 sheep、fountain、well」）。

格數＝在遊戲地圖上佔的大小（寬×高）；畫面比例＝請 ChatGPT 產生的長寬比。
**建議先做每區的「★主角」**，有了最有感；其他慢慢補，沒圖的會繼續畫色塊。
