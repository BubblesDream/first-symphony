# 城堡角色圖：生成方式與提示詞

> 2026-11-05 後來改成：**成員用紙娃娃**（`docs/提示詞-城堡紙娃娃.md`），這份每人一張的做法目前只給訪客 `visitor` 用。
> 想要特別造型的成員也可以照這份生一張，登記在 `art.js` 的 `CHAR_ART`，會優先於紙娃娃。

## 1. 規格

- 一人一張透明背景 PNG，橫向 3:2：**正面、背面、朝右側面**排成一列，大小一致、腳底在同一條線。
- 遊戲裡顯示高度 1.25 格（`art.js` 的 `CHAR_H`），朝左由程式左右翻轉。走路是整個人輕晃，坐下只露出上半身。
- 原圖：`docs/素材/城堡原圖/members/<成員 id>.png`（訪客是 `visitor.png`）。
- 成品：`python tools/castle_images.py` 產生 `assets/images/castle/members/<id>.webp`（三格一列，每格 72×120）。
  這支程式會重做所有圖，Pillow 版本不同時舊圖位元組會變：**只提交新的角色圖**，其他用 `git checkout -- assets/images/castle/*.webp` 還原。
- 在 `art.js` 的 `CHAR_ART` 加一行（`m05: { src: `${DIR}members/m05.webp` }`），跑 `node tools/check_castle.mjs`。

## 2. 用 Codex 生成（本機）

`D:/UserData/Documents/WS/WS_codex_gen_image` 的 `chio.codex_gen`（用該專案的 `.venv/Scripts/python`），模型 `gpt-6.1-terra`、輕度推理（小包裝程式在 `codex exec` 後面加 `-m gpt-6.1-terra -c model_reasoning_effort="low"`）。
參考圖附 `docs/素材/城堡原圖/table_round.png` 與一張已完成的角色原圖（例如 `members/m01.png`），畫風與比例會比較一致。一張約 70～90 秒，可同時跑 3 張。

## 3. 提示詞

共同部分（英文，照貼）：

```
A character sprite sheet for a warm fantasy 16-bit Japanese RPG style game, matching the style of the attached reference furniture images exactly (same line weight: thin dark-brown outlines; same soft painterly pixel shading with light from the upper left; same medium saturation and warm palette). Top-down 3/4 RPG view.

Draw ONE chibi character (about 2.5 heads tall, cute, friendly), full body, three times in a single horizontal row with wide transparent gaps between them, all at exactly the same size and with feet on the same baseline:
1. left: facing the viewer (front view)
2. middle: facing away (back view)
3. right: facing right (side view, walking pose neutral, standing)
Standing upright, arms relaxed at the sides, empty hands. No ground shadow, no floor, no background, no text, no frame. Transparent background. Image aspect ratio 3:2 (landscape). Completely original design, do not imitate any existing game character.

The character:
```

接著寫這位成員的外觀（從問卷欄位翻成英文，顏色附色碼）：

```
- Hair: <髮色名稱> (<#色碼>), <髮型>.
- Skin: <膚色> (<#色碼>).
- Clothes: <上衣>, <下身>, <鞋子顏色> shoes.
- <配件，沒有就寫 No accessories.> <表情，例如 A cheerful smiling expression.>
```

髮型對照：短髮 short hair／中長髮 shoulder-length hair／長髮 long straight hair down to the middle of the back／馬尾 a ponytail／雙馬尾 twin tails／包包頭 tied up in a round bun on top of the head。
上衣對照：襯衫 a shirt／外套 a short jacket over a white shirt／輕鎧甲 light leather-and-metal armor／長袍 a long robe／洋裝 a knee-length dress。

## 4. 驗收

- 三個方向都在、透明背景、側面朝右；`castle_images.py` 找不到 3 個方向會列在「注意」。
- 貼進遊戲看：和其他人身高差不多、顏色和問卷相符。
- 示範資料的角色圖（目前 m01、m02）在收到成員真正的問卷後要重生。
