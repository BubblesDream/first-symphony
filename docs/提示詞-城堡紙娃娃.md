# 城堡紙娃娃：部件生成方式與提示詞

> 管理員 2026-11-05 決定：成員角色改用紙娃娃（研究過程見 `docs/研究-城堡紙娃娃.md`）。
> 成員填問卷（款式＋顏色）就自動有角色，不用每人生圖。個人角色圖（`docs/提示詞-城堡角色圖.md`）目前只給訪客用。

## 1. 部件一覽

原圖都在 `docs/素材/城堡原圖/紙娃娃/`，全部是「照母版 `base.png` 重畫、只改一處」：

| 部件 | 名稱 | 張數 | 參考圖（第一張） |
|---|---|---|---|
| 母版（短髮、短袖、長褲） | `base` | 1 | 研究時生成 |
| 頭：髮型 × 頭上配件 | `head_<髮型>_<none/hat/ribbon/headband>` | 6 × 4 | 無配件的版本參考 `base`；有配件的參考同髮型的 `_none` |
| 衣服：上衣 × 下身 | `outfit_<shirt/jacket/armor>_<pants/shorts/longskirt/skirt>`、`outfit_robe`、`outfit_dress` | 14 | `base` |
| 臉部疊圖（眼睛、眉毛、嘴；眼珠鍵色藍） | `face_<名稱>` | 試做 3（base、smile、cool） | `base` |
| 疊在上面的配件 | `over_glasses`、`over_cape` | 2 | `base` |

`head_short_none` 就是母版本身（不用另外生）。髮型：short 短髮、medium 中長髮、long 長髮、ponytail 馬尾、twintails 雙馬尾、bun 包包頭。

鍵色（程式靠顏色分區、再染成每個人的顏色）：頭髮綠 `#22c55e`、上衣洋紅 `#d946ef`、下身藍 `#2563eb`、鞋子青 `#06b6d4`、配件黃 `#facc15`；皮膚用自然的淺桃色（程式依顏色辨認）。白色、金屬、皮帶、外框是固定色，不會被染。

## 2. 生成（本機 Codex）

和 `docs/提示詞-城堡角色圖.md` 第 2 節相同：`WS_codex_gen_image` 的 `chio.codex_gen`，模型 `gpt-6.1-terra`、輕度推理。參考圖依序附：上表的參考圖、`docs/素材/城堡原圖/table_round.png`（畫風）。一張約 70～80 秒，可同時跑 4 張。

### 頭與配件（`HEAD`）

```
The FIRST attached image is a paper-doll template sheet (front, back and right-side views of one chibi character). Redraw it as a new image that matches it EXACTLY: same canvas size 1536x1024, the same three views at exactly the same positions and the same size on the canvas, same pose, same face, same body, same clothes, same style (warm fantasy 16-bit Japanese RPG pixel art, thin dark-brown outlines, soft shading lit from the upper left). Change ONLY: <改什麼>

Flat key colors so a program can recolor them (shade ONLY with lighter/darker versions of the same hue, never mix in other hues):
- hair: vivid key green (#22c55e)
- top: key magenta (#d946ef); trousers: key blue (#2563eb)
- any accessory item (hat, ribbon, headband, glasses, cape): vivid key yellow (#facc15)
Skin, face, eyes and shoes stay as in the template. Transparent background, no ground shadow, no floor, no text, no frame.
```

`<改什麼>`：
- 髮型：`the hairstyle. New hairstyle: <描述>.`
  medium `shoulder-length hair with soft bangs`；ponytail `a single ponytail tied high at the back of the head, reaching the shoulder blades, with bangs`；bun `hair tied up in a round bun on top of the head, with bangs`；long `long straight hair down to the middle of the back (...)`；twintails `twin tails tied high on both sides of the head, reaching the shoulders, with short bangs`。
- 帽子：`add a simple soft felt hat with a small brim, sitting on the head (key yellow). Keep the hairstyle exactly the same, hair visible under the hat.`
- 蝴蝶結：`add one big ribbon bow tied in the hair at the back of the head, visible from all three views (key yellow). Keep the hairstyle exactly the same.`
- 髮箍：`add a plain smooth headband over the top of the head from ear to ear (key yellow). Keep the hairstyle exactly the same.`
- 眼鏡：`add simple round glasses on the face (thin key yellow frames, clear lenses showing the eyes). Keep everything else the same.`
- 披風：`add a short cape fastened at the neck, falling behind the back to the waist (key yellow, plain, no pattern). Keep everything else the same.`

### 衣服（`OUTFIT`）

```
The FIRST attached image is a paper-doll template sheet (front, back and right-side views of one chibi character). Redraw it as a new image that matches it EXACTLY: same canvas size 1536x1024, the same three views at exactly the same positions and the same size on the canvas, same pose (standing, arms relaxed at the sides), same head, same face, same short hair, same body proportions, same style (warm fantasy 16-bit Japanese RPG pixel art, thin dark-brown outlines, soft shading lit from the upper left). Change ONLY the clothes and shoes.

New outfit: <上衣>; <下身>.
Shoes: simple ankle boots in vivid key cyan (#06b6d4).

Flat key colors so a program can recolor them (shade ONLY with lighter/darker versions of the same hue, never mix in other hues):
- hair stays vivid key green (#22c55e)
- main clothing color: key magenta (#d946ef)
- lower clothing color (trousers / shorts / skirt): key blue (#2563eb)
- shoes: key cyan (#06b6d4)
White parts, metal parts and belts keep natural colors. No other colored patterns. Transparent background, no ground shadow, no floor, no text, no frame.
```

- 上衣：shirt `a simple long-sleeved shirt with a small collar, tucked in, with a plain brown belt`；jacket `a short open jacket with long sleeves over a plain white shirt (the shirt is natural white, the jacket is key magenta)`；armor `light adventurer armor: a padded tunic in key magenta with a natural steel-gray metal breastplate and small steel shoulder guards, plain brown belt`。
- 下身：pants `straight long trousers (key blue)`；shorts `knee-length shorts (key blue), bare lower legs`；longskirt `an ankle-length flowing skirt (key blue)`；skirt `a knee-length flared skirt (key blue), bare lower legs`。
- 連身（整句取代「上衣; 下身」）：robe `a long ankle-length robe with wide long sleeves in key magenta, tied with a plain brown rope belt. No trousers visible.`；dress `a knee-length dress with short puffed sleeves in key magenta, with a small natural white collar, bare lower legs. No trousers.`

### 臉（`FACE`）

提示詞與每種臉的描述在 `docs/研究/紙娃娃臉/gen_faces.py`（`python gen_faces.py smile cool ...`）。重點：只改正面與側面的表情、眼睛位置與大小不變、眉毛維持鍵色綠、眼珠鍵色藍 `#2563eb`（深藍瞳孔、保留白色反光）。表情要誇張一點，遊戲大小下眼睛只有 2～3 像素。新的臉還要加進 `roster.js` 的 `FACE_STYLE`（檢查程式會比對）。

## 3. 處理與登記

1. 原圖放 `docs/素材/城堡原圖/紙娃娃/<名稱>.png`。
2. 名稱加進 `assets/js/castle/art.js` 的 `DOLL_PARTS`（新款式還要在 `paperdoll.js` 的 `dollParts` 與 `roster.js` 的款式對照加上）。
3. `python tools/castle_paperdoll.py [名稱 ...]`（需要 Pillow、numpy；不給名稱就全部重做）。輸出 `assets/images/castle/doll/<名稱>.webp`，並印出每個方向的對齊位移；超過 8 像素會提醒檢查。
4. `node tools/check_castle.mjs`，再開 `hall.html` 看：要貼進場景、用遊戲大小比較，不要只看單獨的圖。

## 4. 驗收重點

- 三個方向都在、位置和母版一致（位移小）、側面朝右。
- 鍵色要乾淨：頭髮、衣服不要混進別的顏色；配件只用黃色。混了的部分會變成固定色，染色後看得出來。
- 組合起來看接縫：脖子（切線在母版上衣上緣）、長髮蓋衣服、披風在背後。
