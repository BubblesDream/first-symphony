# 城堡成員外觀問卷（給公會成員填）

> 用途：虛擬公會城堡的小人（NPC）要畫成每位成員的樣子。
> 角色是「紙娃娃」做法：髮型、衣服、配件是事先畫好的部件，再由程式染上每個人的顏色，所以**只能從下面的選項裡挑**。填了選項以外的答案，管理員會換成最接近的選項（例如「長袖」→ 襯衫）。
> 不填也沒關係，沒填的人由程式自動配色。

## 一、複製給成員的填寫範本

把下面這段直接貼到群組，請成員照格式回覆（每一行冒號後面填答案，不想填的留空）：

```
【城堡角色外觀】
遊戲暱稱：
髮型（短髮／中長髮／長髮／馬尾／雙馬尾／包包頭）：
髮色：
膚色（白皙／自然／小麥／深色）：
上衣（襯衫／外套／輕鎧甲／長袍＊／洋裝＊）：
上衣顏色：
下身（長褲／短褲／長裙／短裙）（上衣選＊的不用填）：
下身顏色：
鞋子顏色：
配件（無／帽子／蝴蝶結／眼鏡／披風／髮箍）（選一個）：
配件顏色：
拿手樂器（鋼琴／小提琴／長笛／豎琴／魯特琴／大提琴／不演奏）：
最喜歡待的房間（大廳／演奏室／酒館／練習室／鍛造工坊／外庭／客房／圖書館／觀星台）：
想說的話（1～3 句，會在城堡裡和訪客聊天時出現；可註明在哪個房間說）：
```

## 二、顏色怎麼填

請盡量從這 16 個顏色裡挑（寫名字就好），程式會換成對應的色碼。真的找不到，可以寫「其他：#色碼」或簡單描述（例如「偏紫的粉紅」），由管理員換成最接近的顏色。

| 名稱 | 色碼 | 名稱 | 色碼 |
|---|---|---|---|
| 黑 | `#2e2420` | 白 | `#f5efe2` |
| 深棕 | `#4a3426` | 灰 | `#8a8580` |
| 棕 | `#8a5a3a` | 銀 | `#c8c8d0` |
| 金 | `#d8b45a` | 紅 | `#a8323a` |
| 橘 | `#d9793a` | 粉紅 | `#e09ab0` |
| 黃 | `#e8c84a` | 綠 | `#4f8a4a` |
| 水藍 | `#7ab0d8` | 深藍 | `#2f4a86` |
| 紫 | `#7a5a9c` | 酒紅 | `#6a2a3a` |

膚色另外四種：白皙 `#f6e0cc`、自然 `#f3d6bd`、小麥 `#e0b48a`、深色 `#a8744a`。

## 三、管理員整理用：試算表欄位

收到回覆後，整理到「城堡外觀」分頁（一列一位成員，對應 `data/castle_looks.json`）。欄位名稱與填法：

| 欄位 | 內容 | 例子 |
|---|---|---|
| `member_id` | 成員 id（成員分頁的 id） | `m01` |
| `hair_style` | 短髮／中長髮／長髮／馬尾／雙馬尾／包包頭 | `馬尾` |
| `hair` | 髮色色碼 | `#d8b45a` |
| `skin` | 膚色色碼 | `#f3d6bd` |
| `top_style` | 襯衫／外套／輕鎧甲／長袍／洋裝 | `外套` |
| `top` | 上衣色碼 | `#2f4a86` |
| `bottom_style` | 長褲／短褲／長裙／短裙（長袍、洋裝留空） | `長裙` |
| `bottom` | 下身色碼 | `#2e2420` |
| `shoes` | 鞋子色碼 | `#4a3426` |
| `accessory` | 無／帽子／蝴蝶結／眼鏡／披風／髮箍 | `蝴蝶結` |
| `accent` | 配件色碼 | `#a8323a` |
| `instrument` | 鋼琴／小提琴／長笛／豎琴／魯特琴／大提琴／不演奏 | `小提琴` |
| `favorite_room` | 最喜歡待的房間（會比較常出現在那裡） | `演奏室` |
| `is_demo` | 真的由成員填的寫 `false` | `false` |

「想說的話」放到「城堡台詞」分頁（對應 `data/castle_lines.json`），一句一列：

| 欄位 | 內容 |
|---|---|
| `id` | 台詞編號（例如 `l101`，不重複即可） |
| `member_id` | 成員 id |
| `room` | 在哪個房間說（空白＝任何房間） |
| `text` | 台詞 |
| `is_demo` | `false` |

## 四、注意

- 只放遊戲暱稱，不放真實姓名或聯絡方式。
- 外觀是「參考自己的遊戲角色」挑選項，不使用遊戲官方的角色圖片。
- 像素小人（示範中）已經會用上表的款式與顏色欄位；舊欄位 `outfit`、`mark` 仍然可用。
