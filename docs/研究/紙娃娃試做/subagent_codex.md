建議先試「**固定母版＋少量 AI 款式＋人工校正拆層＋遮罩染色**」。讓 AI 提供畫風，讓固定座標與遮罩負責組裝；30～60 人可共用素材，不必每人生成。

以下張數以「一張含三方向」計，均不含重試。

**六種做法**

| 做法 | 原理、張數 | 對齊／換色／遮擋與風險 |
|---|---|---|
| 只染色、不換款 | 生成 K 套完整角色，K 張 | 無接縫；人工分髮、衣、褲遮罩後染色，原有遮擋保留。最穩，但造型選擇少。 |
| 頭＋身體 | H 種頭、B 種身體，約 H＋B 張 | 以頸中心及頭部比例校正；分區染色。長髮仍須拆前後層；只對脖子一點無法修正角度與肩寬。 |
| **固定母版拆層** | 母版1張，新增款式各約1張 | 固定姿勢、畫布與錨點；人工校正一次，分前後髮、身體、配件。遮罩保護裝飾；風險是初期整理成本。 |
| 遮罩局部編輯 | 母版1張，每款約1次編輯 | 編輯區外直接貼回原母版，保住身體；修改區仍須對齊、拆層及染色。API 有遮罩不等於 CLI 有提供，後者不確定；遮罩也不保證精準邊界。[官方說明](https://developers.openai.com/api/docs/guides/image-generation) |
| 同張圖畫全部零件 | 理想1張，實務按容量分批 | 同圖有助風格一致，不能保證座標一致；每件仍需校正、遮罩與前後層。被遮住的像素不存在，不能靠裁切還原；零件多會壓縮細節。 |
| 全組合矩陣 | H髮×U上衣×L下身×A配件，共HULA組 | 完整角色避免接縫，顏色另染；每組仍需校正三方向。可只做常用組合，但組合數快速膨脹。 |

**建議的最小試做**

1. 選一張最符合家具的角色當風格參考；製作三方向、無髮且衣領完整的固定身體。生成短髮、長髮兩款，各附同一母版；約3張三視圖。
2. 在原解析度逐方向標定頸中心、雙眼中心（背面用耳位／頭側）、肩端、腳底。用共同且未變動的特徵估平移、等比縮放、旋轉；**不要用含頭髮的外接框**。側面獨立校正；透視不同就重選或人工修，別硬拉伸。
3. 每方向拆成「後髮→身體與臉→前髮→配件」。背面長髮可放身體前；帽子另配髮型裁切遮罩，不能只蓋帽圖。素材各整理一次，接受者不再逐人修。
4. 人工確認髮、上衣、褲的獨立遮罩；鍵色只協助初選，不能把顏色辨識當可靠分層。以 **OKLab 的 L 明度**映射目標色的暗／中／亮三色漸層，再轉回 sRGB。外框、金屬、白領口排除；高光降低染色權重、保持低彩度，保留原透明度。
5. 染深棕與淺金兩色，組成2髮×2色×3方向，共12格。先在高解析度合成，再統一縮至72×120；離線輸出靜態素材即可。若要問卷即時預覽，Canvas 合成後快取，不需伺服器。

**及早判斷是否值得繼續**

最大風險是**每新增一款，都要重新修所有搭配**，素材庫沒有真正共用。

先拿上述12格放進實際30～40像素場景，檢查長髮、淺色髮、背面與坐姿：接縫是否可見、兩髮是否可辨、光向是否一致、衣領有無染髒。左翻也會翻轉打光與不對稱配件，須一起看。

若每款能一次整理後通用，就擴充；若仍需逐組修，先退到「少量完整套裝＋分區染色」。連這也缺乏辨識度，再考慮每人一張。
