# 虛擬公會城堡：圖片素材規格與 ChatGPT 提示詞

> 用途：管理員用網頁版 ChatGPT 產生城堡的地板、牆壁、家具圖片，AI 代理負責裁切、縮放並放進遊戲。
> 第一批只做**公會大廳＋演奏室**（目前遊戲裡已有的兩間），角色圖片之後再做。
> **進度（2026-11-05）**：A～D 已完成並放進遊戲，只差 `chair_side.png`。補強用的第二批見 `docs/提示詞-城堡圖片-第二批.md`。

## 1. 共同規格（每張都一樣）

| 項目 | 規格 |
|---|---|
| 視角 | **俯視 3/4 視角**（從斜上方往下看，看得到物品的頂面與正面），和平面配置草圖相同 |
| 風格 | 溫暖的奇幻像素風（16-bit 日式 RPG 感），乾淨、可愛、不華麗 |
| 背景 | **透明背景 PNG**（地板、牆壁這種「拼貼用」的圖除外，它們要填滿整張） |
| 一張圖 | **只放一個物品**，置中，四周留一點空白，不要文字、不要浮水印、不要邊框 |
| 光線 | 光從左上方來；不要畫投射到地面的大影子（遊戲裡會自己加） |
| 色調 | 暖色木頭、米色石材、深紅地毯、深藍旗幟，彩度中等 |
| 原創 | 不可模仿任何遊戲官方的美術、角色或 LOGO |

遊戲的格子是 32×32，畫面會放大 2 倍顯示，所以最後會縮成「**每格 64 像素**」。ChatGPT 產生的圖比較大沒關係，由 AI 代理縮小。下表的「格數」是物品在地圖上佔的大小，「畫面比例」是請 ChatGPT 產生的長寬比。

## 2. 使用方式

1. 在**同一個** ChatGPT 對話裡連續產生，風格比較一致。
2. 第一則訊息先貼「共同風格說明」（下面的灰色框），可以順便附上平面配置草圖，說「參考這張的風格」。
3. 之後每張只要貼該物品的提示詞。
4. 不滿意可以說「同樣風格，再一張」「顏色再暗一點」「去掉影子」。
5. 下載後**照下表的檔名**命名（英文小寫），放進 GitHub 的 `docs/素材/城堡原圖/` 資料夾：在 GitHub 網頁進入該資料夾 → **Add file → Upload files** → 拖進去 → **Commit changes**。資料夾不存在時，在上傳畫面的檔名前面打 `docs/素材/城堡原圖/` 就會自動建立。
6. 上傳後，開新的工作階段請 AI 代理處理（提示詞見 `docs/交接-虛擬城堡.md` 或對話紀錄）。

## 3. 共同風格說明（第一則訊息先貼這段）

```
接下來我要請你幫我畫一系列 2D 遊戲素材，請全部維持同一個風格：
- 溫暖的奇幻像素風（16-bit 日式 RPG 感），俯視 3/4 視角（從斜上方往下看）。
- 一張圖只畫一個物品，置中，透明背景 PNG，不要文字、浮水印、邊框。
- 光從左上方來，不要畫投射到地面的大影子。
- 輪廓用深咖啡色細線，色調溫暖（暖木頭、米色石材、深紅、深藍），彩度中等，不要金色發光或特效。
- 完全原創，不要模仿任何現有遊戲的美術或 LOGO。
這是一座音樂公會「第一交響樂團」的城堡，主題是音樂與生活。之後我會一張一張告訴你要畫什麼。
```

## 5. 之後的批次（先不用做）

- 角色：像素小人（4 個方向 × 走路 2～4 張），以及分開的髮型、衣服、配件，方便換裝。規格等房間做好後再訂。
- 交流廳（酒館）：吧台、酒桶、圓桌、長椅、酒杯。
- 城堡外庭：羊、羊圈柵欄、紡車、工作台、花圃、水井、噴泉、樹。
- 練習室：稻草人、箭靶、武器架。
- 客房：床、衣櫃、書桌、窗戶。

## 6. AI 代理處理圖片時的規則（給下一個工作階段）

- 原圖放在 `docs/素材/城堡原圖/`（只保存，不給網站讀）。
- 處理後的成品放在 `assets/images/castle/`（這個資料夾不是同步程式管理的，可以手動修改），檔名相同，格式 PNG 或 WebP。
- 用 `python3 tools/castle_images.py` 處理（大小讀自 `assets/js/castle/art.js`，新增圖片先在那裡加一行）。
- 處理步驟：裁掉透明邊 → 依「格數」縮放到每格 64 像素（例如 2×2 的桌子約 128×128，比格子高的物品依比例放大高度）→ 確認透明背景真的透明（ChatGPT 偶爾會畫成白底或棋盤格，要去掉）→ 壓縮。
- 拼貼用的圖（地板、牆）要檢查接縫；接不起來就裁中間一塊重新做成可拼貼的版本。
- 遊戲裡沒有圖或圖載入失敗時，一律退回現在的色塊，不能讓遊戲壞掉。
