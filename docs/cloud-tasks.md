# 雲端工作階段任務

在 claude.ai/code 選擇 `BubblesDream/first-symphony`，每個方向各開一個工作階段，貼上「共同指示」，並把其中的方向段落換成該方向。三個 PR 都會改到同一批檔案，**只合併其中一個**，其餘關閉。

三個方向都以 `docs/reference/home-mood.png` 的氛圍為基礎（暖米白紙張、深咖啡文字、回憶錄感），差別在**裝飾程度與版面重心**。

## 共同指示（每個工作階段都要貼）

```
請先閱讀 CLAUDE.md、docs/spec.md，並查看參考圖 docs/reference/home-mood.png，依規格建立第一版網站，完成 spec 第六節的全部範圍並執行第七節的驗證。

本次的視覺方向如下（只影響外觀與版面節奏，不改變功能、資料結構與頁面架構）：
<貼上下面其中一個方向>

完成後：
- 在分支 <分支名稱> 提交，開 Pull Request 到 main，PR 標題為「第一版網站：<方向名稱>」。
- PR 說明開頭用三到五句話描述這個視覺方向的設計決定（配色、字型、版面、裝飾取捨）。
- 不要修改 CLAUDE.md 與 docs/。
```

## 方向 A：回憶剪貼簿（分支 `design/scrapbook`）

```
方向 A「回憶剪貼簿」：最接近參考圖。保留紙膠帶標籤式的區塊標題、拍立得照片（白邊、少量傾斜）、膠卷框影片縮圖、手寫感短句。首頁採參考圖那種雙欄卡片區塊（但不要右側文章側欄）。裝飾全部用 CSS 與小型 SVG 完成，不用大型背景圖，並確保手機版不會因為傾斜與裝飾而擁擠。
```

## 方向 B：簡潔回憶錄（分支 `design/memoir`）

```
方向 B「簡潔回憶錄」：沿用參考圖的配色與字型氣質（米白底、深咖啡字、有份量的標題字），但把裝飾減到最少：不用紙膠帶、不傾斜照片、不用手寫字型，只保留細線、留白與一個低彩度強調色。版面像一本排版乾淨的紀念冊，閱讀舒適、維護最容易。
```

## 方向 C：相簿優先（分支 `design/album`）

```
方向 C「相簿優先」：同樣是米白紙張與深咖啡色調，但讓照片成為主角。首頁橫幅接近滿版，精選回憶以大圖格線呈現，照片可有拍立得白邊但不傾斜；文字精簡。紙膠帶與手寫感只在少數地方點綴（例如橫幅引言、頁尾）。
```

## 合併之後

1. 在 GitHub 合併選定的 PR，關閉其他兩個。
2. Settings → Pages → Source 選「Deploy from a branch」，Branch 選 `main`、資料夾 `/ (root)`。
3. 幾分鐘後開啟 `https://bubblesdream.github.io/first-symphony/` 確認。
