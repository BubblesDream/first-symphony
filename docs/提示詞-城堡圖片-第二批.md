> 共同規格、風格說明與上傳方式和 `docs/素材規格-城堡圖片.md` 相同：**在同一個 ChatGPT 對話裡先貼「共同風格說明」**，再一張一張貼下面的提示詞。

## 怎麼交給 AI 代理

兩種方式都可以：

1. 照下表檔名命名，上傳到 GitHub 的 `docs/素材/城堡原圖/`。
2. 直接貼在對話裡，並依序說明是哪幾張（例如「依序是 chair_side、curtain_stage」）。

格數＝在遊戲地圖上佔的大小；畫面比例＝請 ChatGPT 產生的長寬比。
